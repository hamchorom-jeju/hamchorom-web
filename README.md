# 🍊 함초롬 제주 농장 통합 주문 관리 시스템 (Hamchorom Farm Web)

![Version](https://img.shields.io/badge/version-1.2.0-orange)
![Platform](https://img.shields.io/badge/Platform-Google_Apps_Script-green)
![API](https://img.shields.io/badge/AI-Gemini_API_Integrated-blue)

함초롬 제주 농장의 직거래 주문 관리와 고객 소통을 자동화하기 위한 전문 ERP 시스템입니다. 복잡한 주문 과정을 단순화하고, 고객에게 실시간 주문 상태를 제공하여 농장 운영의 효율성을 극대화합니다.

---

## ✨ 주요 기능 (Key Features)

### 📦 5단계 동적 주문 추적
- **실시간 상태 업데이트**: 주문 접수, 입금 확인, 상품 준비, 배송 중, 배송 완료의 5단계 UI 제공.
- **애니메이션 상태바**: 고객이 직관적으로 배송 현황을 파악할 수 있는 시각적 요소 적용.

### 📝 스마트 주문 수정 및 관리
- **고객 직접 수정**: 배송 시작 전, 고객이 직접 배송지나 메시지를 수정할 수 있는 안전한 인터페이스.
- **관리자 전용 대시보드**: 대량의 주문 데이터를 필터링하고 송장 번호를 일괄 관리하는 기능.

### 🤖 Gemini AI 홍보 엔진
- **자동 슬로건 생성**: 구글 Gemini API를 연동하여 농장 홍보 문구 및 마케팅 메시지 자동 생성.
- **콘텐츠 최적화**: 블로그 및 SNS용 포스팅 가이드 제공.

### 🎨 프리미엄 디자인 & 경험
- **글래스모피즘 UI**: 고급스러운 투명도와 그라데이션이 적용된 현대적 디자인.
- **모바일 퍼스트**: 농사일 중에도 스마트폰으로 간편하게 관리할 수 있는 반응형 웹.

---

## 🛠 기술 스택 (Tech Stack)

- **Backend**: Google Apps Script (GAS)
- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **AI Integration**: Google Gemini Pro API
- **Data Source**: Google Sheets

---

## 📂 프로젝트 구조 (Structure)

- `app.js`: 메인 프론트엔드 비즈니스 로직 및 UI 제어
- `index.html`: 메인 웹 애플리케이션 인터페이스
- `style.css`: 글래스모피즘 기반의 프리미엄 스타일시트
- `google_apps_script.js`: 서버 사이드 API 및 데이터베이스 통신 로직
- `package.json`: 프로젝트 메타데이터 및 환경 설정
